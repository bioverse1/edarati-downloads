نظام إدارة المدارس والمعاهد والكليات. البرنامج نفسه يشتغل من https://edarati-iq.web.app ،
فكل تحديث يوصل لكل الأجهزة فوراً بدون تحميل نسخة جديدة.

## الطريقة المستحسنة (بدون أي رسالة تحذير)

افتح https://edarati-iq.web.app بمتصفح **كروم** أو **إيدج** (بالحاسبة أو الموبايل) واضغط
**«ثبّت البرنامج على هذا الجهاز»** بصفحة الدخول. يتنصّب بأيقونته ونافذته مثل أي برنامج، بدون تحميل ملفات.
